# RUDA Storefront Design System（项目二专用）

- 文档状态：**设计基线已定**；21 套模板的视觉原型属阶段 B
- 日期：2026-10-31
- 项目：`P2-STORE-TEMPLATES`
- 定位：商家**私人独立网站**（`<storeSlug>.ruda.fashion`）的设计系统。**不适用于商家后台**（后台见 `design-values.md` 与 `merchant-seven-industry-ui-upgrade.md`）。

## 1. 规则优先级

冲突时自上而下：

1. 用户明确提出的设计要求。
2. 本文件 + `design-values.md`（RUDA 品牌与网站规范）。
3. 商家所属行业的视觉方向（§4）。
4. 外部设计技能的一般建议（`impeccable` / `landing-page-design` / `frontend-design`）。

**禁止**把多个技能的默认配色、字号、圆角、动效规则直接混合。技能只能在本文件划定的范围内给建议。

## 2. 与后台的关键差异（必须理解）

| 维度 | 商家后台 | 私人网站 |
| --- | --- | --- |
| 目的 | 高效操作 | 品牌表达 + 下单转化 |
| 商家品牌色 | **不允许**（统一 RUDA 令牌） | **允许**，但只在店铺作用域、且需可读性校验 |
| 布局密度 | 高密度、表格驱动 | 留白优先、图片优先 |
| 圆角 | `--radius-ruda-*`（2px / 手机 6-8-6-10-4） | 同一套令牌；电商型模板允许在卡片上使用 `--radius-ruda-card` 的放大值（≤8px），**不得**出现 `rounded-3xl` 或胶囊卡片 |
| 字体 | 全 sans | 买家侧可用 `--font-serif` / `--font-editorial` 做展示字 |
| 动效 | 克制、几乎无入场 | 允许一次有意图的入场与滚动显现 |

## 3. 布局骨架（3 种，21 套由三者 × 行业内容块组合）

| 骨架 | 首屏 | 商品展示 | 导航 | 适用模板 |
| --- | --- | --- | --- | --- |
| **Editorial（编辑式）** | 全幅影像/视频 + 大字标题 + 一句话定位 | 双栏错落、大图、少信息（名/价/起订） | 居中文字标签 + 抽屉菜单 | 品牌官网类（贸易 A、箱包 A、连锁 A、零售 A/C） |
| **Catalog（目录式）** | 分类入口 + 搜索前置 | 密集网格 + 左侧分类栏 + 规格筛选 | 左侧分类栏 + 顶部搜索 | 目录类（百货 B、箱包 B、贸易 B） |
| **Commerce（商城式）** | 促销位 + 分类快捷入口 + 主推商品 | 卡片网格，价格/MOQ/加购同屏 | 顶部多级菜单 + 购物车常驻 | 商城类（贸易 C、百货 C、箱包 C、连锁 C、零售 B） |

三套骨架的 DOM 结构、断点行为、导航形态必须不同；**不允许同一骨架改色当成另一套模板**。

## 4. 行业视觉方向

| 行业 | 关键词 | 禁止 |
| --- | --- | --- |
| 服装生产批发 / 服装批发 | **保留现有三套**，只做缺陷诊断 | 用新模板替换；统一视觉强行改造 |
| 贸易批发 | 国际供应能力、流程清晰、可信 | 虚构采购分析、假汇率 |
| 百货批发 | 多品类秩序感、目录效率、筛选强 | 满屏卡片堆叠、无层级 |
| 箱包批发 | 意大利奢品、材质特写、画册感 | 做成普通百货商城；滥用金色 |
| 百货连锁 | 集团权威、门店地图感、多门店秩序 | 展示虚假门店数据 |
| 综合零售 | 精选感、促销节奏、购买顺畅 | 伪造销量/评价 |

## 5. 色彩

- 基础：`design-values.md` 的暖中性色阶（`#fbfaf8` / `#f5f3ef` / `#e9e6df` / `#12110f` / `#201e1a`）。
- **商家品牌色**：可由商家设置进入店铺主题，但必须满足
  1. 只通过 `data-storefront-template` 或店铺根作用域生效；
  2. 正文字对比度 ≥4.5:1、大字 ≥3:1，不达标时自动回落到墨色；
  3. 不得进入平台其他页面、后台或全局令牌。
- 现有两套例外：`luxury_black_gold`（`#c9a96e`）、`ecommerce_standard`（`#2563eb`）保留原样，但同样受上述作用域约束。
- **禁止**：紫蓝 AI 渐变、渐变文字、玻璃拟态、发光、3D 装饰、大面积投影。

## 6. 排版

| 用途 | 值 |
| --- | --- |
| 展示标题（Editorial） | `--font-serif`，`text-5xl`–`text-7xl`，`tracking-tight` |
| 品牌字标 | `--font-serif` / `.font-brand-display` |
| 商品名 | `--font-sans` `text-sm`–`text-base`，最多 2 行 |
| 价格 / MOQ / 库存 | `--font-sans`，`tabular-nums`，`text-sm` 起 |
| 正文与说明 | `text-sm`–`text-base`，行宽 <80 字符（中文 30–40 字） |

**硬底线**：正文与标签 ≥12px（店铺导航现在的 9–10px 属缺陷，阶段 C 必修）。

## 7. 图片规范

- 商品主图统一 **3:4 或 4:5**；同一模板内所有卡片比例一致，不因图片原始尺寸变形。
- 图片宽度按容器缩放，使用 `srcset`/`sizes` 或固定宽高比 + `object-cover`，避免布局跳动。
- 列表首屏之外懒加载；`priority` 只用于首屏第一张。
- 裂图必须回落为中性占位，**不得**回落到品牌 Logo（会被误读为真图）。
- 视频只用于 Editorial 首屏，`muted playsInline preload=metadata`，并提供静态 poster。

## 8. 交互与状态（每套模板必做）

必做：hover、focus（可见焦点环）、active、加载骨架、空状态、错误、无权限、触控 44px、`prefers-reduced-motion`。

**每个按钮必须有真实业务结果**：加购、询价、联系、筛选、翻页。不允许装饰性按钮。

## 9. 响应式基线

| 断点 | 要求 |
| --- | --- |
| 390 | 单列或双列；主导航进抽屉；筛选进 Bottom Sheet；主操作首屏可见；无横向滚动 |
| 820 | 双列/三列；侧栏可折叠 |
| 1440 | 目录式三至四列、编辑式大图版位；内容最宽 1200–1440px |

手机端不是桌面缩小：每套模板必须有独立的 390 布局决策。

## 10. 数据与授权（不可由模板决定）

- 模板只接收**已过滤**的数据（授权商品过滤在数据装配层完成）。
- 未授权时不得泄漏授权商品的图片、价格、SKU、库存。
- 价格一律经 `calculateCustomerPrice`；库存一律读 SKU 可售量。
- 无真实数据时显示空状态，不得造假。

## 11. 组件清单（按模板组合，不机械堆砌）

导航：品牌 Header、Mega Menu、抽屉导航、分类栏、搜索、账户入口。
商品：网格（多密度）、画廊（多图/放大/视频）、规格选择（颜色/尺码/SKU）、筛选排序分页、快速查看。
B2B：颜色×尺码数量矩阵、MOQ、阶梯价、批量加入、询价、报价申请。
交互：Drawer、Dialog、Popover、Bottom Sheet、图片预览、Toast。
系统：Skeleton、Empty、Error、Permission。

## 12. 完成定义

一套模板只有同时满足：结构与其他两套不同、三档视口可用、真实数据与授权正确、每个按钮有结果、有 `webapp-testing` 截图与操作记录、100 分制 ≥90 —— 才可标记完成。
