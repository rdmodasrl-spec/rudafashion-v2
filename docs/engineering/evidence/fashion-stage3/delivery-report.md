## 3. API 变更（新增）

- `GET /api/fashion/notifications`、`GET /api/fashion/notifications/unread-count`、`POST /api/fashion/notifications/read`、`DELETE /api/fashion/notifications/:id`
- `GET/POST /api/fashion/blocks`、`DELETE /api/fashion/blocks/:accountId`
- `POST/DELETE /api/fashion/posts/:id/hide`
- `GET/POST /api/fashion/drafts`、`PATCH/PUT/DELETE /api/fashion/drafts/:id`
- `GET /api/fashion/creators/:id/followers`、`GET /api/fashion/creators/:id/following`
- `GET /api/fashion/tags`
- `GET /api/fashion/account/analytics`
- `DELETE /api/fashion/posts/:id`（作者软删除，`publicationStatus='deleted'`，保留审核历史）
- `POST /api/fashion/social/:id/follow` 现在会校验目标账号存在；点赞/评论/关注会写通知。

所有写接口均要求时尚账号（HTTP-only JWT Cookie），未引入任何客户端可信身份。
