## 1. 现状清单

### 1.1 渲染入口与组件树

| 层 | 事实 |
| --- | --- |
| 入口 | `src/apps/frontend-web/main.tsx` → `PublicFrontendApp` → `MerchantStoreView` |
| 店铺页组件 | `src/apps/shared/components/frontend/MerchantStoreView.tsx`（**1 037 行，唯一实现**） |
| 样式 | `MerchantStoreView.css`（**158 行，100% 是颜色/边框/圆角/阴影覆盖**） |
| 模板注册表 | `src/shared/merchantStorefrontTemplate.ts`（3 个 id） |
| 域名 | `https://<storeSlug>.ruda.fashion/<lang>/`（`src/shared/merchantStoreUrl.ts`） |
| 复用方 | `frontend-web` 与 `frontend-mobile` 共用同一组件（无独立移动实现） |

**核心结论**：现有「三套模板」= 同一份页面的三套配色皮肤。`MerchantStoreView.tsx` 中 `storefrontTemplate ===` 出现 **0 次**；模板只以 `data-storefront-template` 属性出现（第 337 行，1 处）。因此 21 套目标**无法**通过继续追加 CSS 覆盖实现。

### 1.2 现有页面结构（所有模板共用）

```
header（居中品牌名 + 联系方式）
sticky nav（全部 / 特价 / 授权订做区 + 购物车）
hero（全幅视频，58–72vh）
profile（品牌简介）
products（单一网格，商品卡：图 / 名 / 价 / 库存 / MOQ / 加购）
footer
```

- 商品详情：点击商品卡后打开**浮层**（`selectedStoreProduct` 状态），**没有独立详情页**。
- 站内搜索、筛选、排序、分页：**均无**。
- 分类：只有 3 个商品桶（new / clearance / custom），**没有商家自定义分类导航**。

### 1.3 数据来源与授权（沿用，不得改）

| 项 | 现状 |
| --- | --- |
| 商品/商家数据 | 来自 `B2BContext`（前端已加载的 products / merchants），按 `merchantId` 过滤 |
| 授权过滤 | `canViewWholesaleProducts`、`isVaultApproved`、`isLockedForBuyer`、`visibility`（wholesale/private）、`isExclusiveProtected`、`lifecycleStatus` |
| 价格 | `calculateCustomerPrice`（按买家折扣率），未认证买家按原价规则 |
| 库存 | SKU 级 `stockCentral` / `getAvailableStock` |
| AI 客服 | `/api/merchant-ai/support/status/:merchantId` |
| 品牌资料 | 商家设置（logo/banner/showroom 图/视频/简介/SEO/配送与退换政策） |
| 模板持久化 | 写入商家 `settings.storefrontTemplate`（`withMerchantStorefrontTemplate`），服务端校验 `isMerchantStorefrontTemplate`，非法值返回 `STOREFRONT_TEMPLATE_INVALID` |

## 6. 开发风险

| 风险 | 说明 | 控制 |
| --- | --- | --- |
| 21 份复制 | 最容易发生的失败模式 | 模板注册表 + 3 种布局骨架 + 行业内容块；禁止复制整页组件 |
| 切换丢数据 | 模板只改 `settings.storefrontTemplate` | 发布前校验 + 保存快照 + 一键回滚；切换只改展示层 |
| 授权泄漏 | 新模板可能绕过现有过滤 | 过滤逻辑集中在数据装配层，模板只能拿已过滤结果；阶段 D 专项验收 |
| 强调色外溢 | 黑金/商城蓝进入全局 | `data-storefront-template` 作用域 + 机械检查 |
| 与项目一提交混杂 | 商家端选择器位于后台 | 选择器改动单独提交、单独验收，不改后台外壳 |
| 前台框架被重构 | 擅自换栈 | 阶段 A–D 不动 React/Tailwind 版本 |
| 假数据冒充 | 无门店/无采购分析却做展示 | 只用真实接口；无数据即空状态 |
| 手机端只做缩小 | 交付质量不达标 | 每套模板必须给 390 布局图与截图 |
