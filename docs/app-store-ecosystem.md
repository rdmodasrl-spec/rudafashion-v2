# RUDA 生态应用商店规格与现状

核查日期：2026-10-23

## 目标与边界

RUDA 生态应用商店目录只管理软件、插件和企业服务，不管理服装商品、SKU、库存或商品订单。应用目录和商家安装记录以 Prisma `App`、`AppCategory`、`AppInstallation` 为权威数据；服装交易继续使用现有商品和订单模型。

当前阶段优先避免将目录记录、付费产品或尚无运行集成的应用描述成已安装/可用。未完成支付、授权、运行时接入或卸载清理的能力，必须保持明确不可用，不得用模拟状态替代。

## 已发现的现状

- 平台管理入口 `app_store_mgmt` 已接入桌面端和平台手机端；页面调用管理员应用列表/分类 API，并能创建和编辑目录应用。
- `scripts/seed-app-store.ts` 创建分类并发布 `ruda-business-email`。脚本不在常规数据库 seed 入口中自动调用，实际生产数据是否已播种待环境验证。
- 商家端 `AppStore.tsx` 已接入 Web 与手机后台的“设置 > 应用管理”入口；小程序未接入。
- 商家目录 API 按当前租户返回发布应用及安装状态；安装、启用、停用、卸载均校验员工权限并写员工审计记录。
- `AppInstallation` 保存租户与应用关系、生命周期状态、安装版本及更新时间。旧记录的安装版本允许为空；启用时记录当前目录版本。代码中未发现通用插件运行时、独立权限授予/撤销、通用配置 Schema、版本升级/回滚或卸载数据清理机制。不得把关系记录等同于运行时已启用。
- 安装和启用仅允许目录已发布、免费且匹配原生运行时版本的应用；付费登记不会创建安装记录。
- 商家邮箱服务状态 API 明确返回 `setup_required`、`mailboxProvisioningAvailable: false`。商家组件只提供域名所有权配置，不提供邮箱账户、Webmail 或收发邮件。
- `ruda-business-email` 种子定义和幂等迁移已调整为免费的邮箱域名配置；在本阶段独立的临时 PostgreSQL 数据库中完成迁移及重放验证，未触及生产库。
- 平台应用目录具备创建、编辑、发布状态治理及安装企业/启用状态查询入口；当前没有用量、错误分析或计费界面。
- 商品商城使用独立的 `Product`、SKU/库存和订单业务模型；没有证据表明 App Store 使用商品商城订单。不得复用服装 SKU 作为应用目录或安装记录。

## 本轮范围与契约

用户确认：暂不开放付费；先审计并只接入有真实实现的原生应用；先接商家 Web 与手机后台，小程序仅在已有可用入口时再评估。用户批准将现有邮箱目录产品范围收窄为**免费邮箱域名配置**，必须明确邮箱服务开通、邮箱账户、Webmail 和收发信均未就绪。

本轮接入唯一原生应用 `ruda-business-email`，其真实功能是通过 TXT DNS 记录验证商家域名所有权。邮箱域名记录属于商家数据，保存在 `MerchantEmailDomain`，不另复制进应用配置表。应用目录页面不得宣称邮箱已托管或可收发邮件。

服务端安装边界：

- 身份：商家租户员工。
- 权限：继续使用既有 `employees.manage` / `store_manager` 授权规则。
- 租户：安装记录只写入已认证的当前商家 ID。
- 可用性：仅支持静态原生运行时注册表中的应用，且目录状态为 `published`、版本与该原生运行时兼容。
- 计费：若 `pricingType` 不是 `free`，返回 `409 APP_STORE_PURCHASE_REQUIRED`；不写安装记录、不发起支付。
- 平台发布：支付能力未开放期间，平台 API 拒绝发布非免费应用；已有付费记录需先下架/设为草稿。
- 生命周期：安装创建 `installed` 记录；显式启用转为 `active`；停用转为 `disabled`；重新启用恢复 `active`；卸载删除安装关联。运行时 API 每次请求均检查应用已发布且租户安装状态为 `active`。
- 版本：新安装记录应用目录版本；启用时同步记录实际启用版本；停用保留版本。历史记录在首次启用前版本为空，不能据当前目录推断旧安装版本。
- 配置：邮箱域名通过现有域名管理 API 持久化；停用/卸载只关闭该应用入口，不删除依法属于商家的域名验证记录。
- 审计：安装、启用、停用、卸载、平台目录创建/更新均写入现有员工或平台审计机制；应用下架时停用所有已启用租户安装并记录操作。
- 错误处理：无效 ID 返回 400；未发布/不存在返回既有 404；付费未购买返回 409；内部异常使用既有服务端错误处理。

## 验收标准

1. 非免费、未发布、无原生运行时或不兼容版本的应用无法安装/启用。
2. 安装、启用、停用、卸载是不同且可持久化的状态变化；只有 active 且已发布的兼容应用 API 才能运行。
3. 邮箱域名添加与 DNS 验证仍调用现有真实服务，数据按商家隔离并在重新登录后可读。
4. 商家 Web 与手机后台从“商家设置 > 应用管理”进入同一目录和生命周期 API。
5. 商店应用标识与服装商品/SKU/订单系统保持分离。
6. 目标构建、资格/状态单测通过；没有隔离数据库时不得声称持久化端到端已验证。
7. 付费、订阅、试用、退款、外部插件执行、二进制应用升级/回滚、通用配置 schema、平台安装错误/用量/账单分析和小程序入口保持明确未实现，直到存在真实契约与实测证据。

## 第二个原生应用：智能生产链（2026-10-25）

- 目录应用：`ruda-production-chain`，名称「智能生产链」，分类 `manufacturing`，版本 `1.0.0`，免费、发布状态；`appStoreNativeRuntimes` 已登记，安装/启用继续复用既有 `AppInstallation` 生命周期与 `employees.manage` 权限。
- 运行时门禁：`/api/production/*` 每个请求校验当前租户 `AppInstallation.status='active'` 且目录应用已发布、版本与运行时一致；未安装返回 `403 PRODUCTION_APP_NOT_INSTALLED`。停用/卸载保留全部生产业务数据。
- 商家端入口：商家 Web 与手机端「设置中心 → 应用管理 → 应用商店 → 智能生产链 → 打开应用」。未安装时仍只能安装，不能打开。
